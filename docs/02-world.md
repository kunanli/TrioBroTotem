# 世界觀與故事

### 圖騰的規則

這片土地的力量來自圖騰。圖騰的成立條件只有一個：**任意三隻不同族的動物疊在一起**。同族疊一百層也沒有用。

在這個世界裡，合作不是美德，是物理法則。

> **設計註記**：規則寫成「任意三隻不同族」而非「特定三族」，是為了讓後續解鎖動物（雞、長頸鹿等）不破壞設定。每多一族只是多一種組合，主題反而更強——野心家的錯誤不是族數不夠，而是他用**強迫**的方式黏合。

### 三大族與元素

最初立起大圖騰的是三個族，也是玩家的起始角色：

| 族 | 元素 | 象徵 | 圖騰位置 |
|---|---|---|---|
| 豬族 | 土 | 承載、力量、地基 | 底層 |
| 蛙族 | 水 | 生命、治療、流動 | 中層 |
| 貓族 | 風 | 遠望、輕盈、視野 | 頂層 |

其餘族群（雞族、長頸鹿族等）不綁定元素，各有自己的象徵。

### 故事線

三族曾共立大圖騰，維持土地平衡。後來三族翻臉拆夥，圖騰倒塌，土地開始腐化，其他族群也四散或被吞沒。

三隻主角是各族派出來的年輕人——不是英雄，是「反正這幾個最閒」的那種人選。任務是沿路把倒下的圖騰重新立起來，救出被腐化力量黏走的族群，最後查明源頭。

**核心主題**：自願的合作 vs 強迫的合作。這也是 Boss 的主題。

### 敘事與機制的對應

| 機制 | 敘事解釋 |
|---|---|
| 一定要三個人 | 三隻不同族才能立圖騰 |
| 疊高 | 就是立圖騰的姿勢 |
| 圖騰補血與充能 | 沿路是古代圖騰遺址，殘留力量 |
| 誤傷可開關 | 三族舊怨未解，「他們到底多不合」就是難度選項 |
| 打飛小怪不殘忍 | 多數小怪是被強行黏上圖騰的受害者，打飛＝解放 |
| 解鎖新動物 | 救出被黏合的族人，他們跟你回營地 |
