# 核心定位

三人連線的輕度合作冒險遊戲。玩家扮演不同族的動物，一邊打怪推進、一邊用物理互動解開場景謎題。核心樂趣不在操作精度，而在「三個人一起把一件簡單的事搞得很複雜」。

**一句話定位**：三隻笨拙的動物疊在一起才叫圖騰，也才叫團隊。

### 設計支柱

| 支柱 | 說明 |
|---|---|
| 重量即規則 | 一個重量數值同時決定抓取、疊高順序、擊退距離、浮力、敵人強度讀值。玩家不必背規則，物理會教。 |
| 合作是物理法則 | 世界觀裡「不同族的動物疊在一起」才有力量，這正好就是遊戲的核心動詞。設定不是裝飾，是機制說明書。 |
| 事故就是內容 | Ragdoll、誤傷、被隊友舉起亂丟——失敗的過程本身要好笑。 |
| 通用動詞保底 | 任何謎題都能用「抓丟疊推」解決；角色專屬能力只是捷徑，不是唯一解。 |

### 規格摘要

| 項目 | 決定 |
|---|---|
| 視角 | 3D 第三人稱跟隨鏡頭 |
| 人數 | 1–3 人，缺額由 AI 夥伴補上 |
| 本地分屏 | 支援 2 人（第三人連線或 AI），動態分屏 |
| 章節數 | 5 章，每章 15–20 分鐘 |
| 總時長 | 約 75–100 分鐘（單周目） |
| 美術風格 | 低多邊形卡通風 |
| 打擊感基準 | Overcooked（回饋速度優先） |
