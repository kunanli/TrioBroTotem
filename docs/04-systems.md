# 核心系統

### 抓取與攜帶

- 只能抓起**比自己輕**的目標（依 4.1 重量階梯）
- 被抓者仍保有鏡頭自由旋轉，移動輸入轉為「掙扎」輸入
- 抓取時可投擲，距離受目標重量影響
- **系統復用**：扛昏迷隊友、兩人合扛原木、搬石頭，共用同一套抓取與負重系統

### 疊高（Stacking）

- 站在隊友頭上進入穩定疊高狀態，底層移動時上層跟隨
- 順序必然由重量決定（重在下、輕在上），玩家不需背規則
- 用途：爬高台、拿高處寶箱、越過斷橋、觸發高處機關
- 底層受攻擊或跳躍時整柱潰散，全員短暫 ragdoll
- **與合體技無關**，兩者為獨立系統

### Ragdoll 與倒地救援

- 血量歸零 → ragdoll 昏迷，**不能自行復活**
- 隊友可扶起（原地，數秒）或扛走（可移動，但扛的人無法攻擊）
- **全隊同時昏迷 = 本章失敗，退回營地重新挑戰**
- **設計效益**：章節內完全不需要檢查點系統，省下整套存檔與重生同步的開發成本
- **代價**：一章 15–20 分鐘是重來成本的上限，此時長不可再往上加

### 誤傷友軍

大廳可開關，但**分成兩層**：

| 層級 | 是否可關閉 |
|---|---|
| 擊退與位移 | **永不可關** |
| 扣血 | 可關 |

**理由**：法師的水球永遠要能把隊友推上高台，否則關掉開關就會卡關。因此**任何謎題都不得設計成「必須靠扣血誤傷才能解」**。

### 合體技：圖騰形態

| 項目 | 設定 |
|---|---|
| 解鎖 | 第三章，三人同時站上圖騰底座完成儀式，永久解鎖 |
| 資源 | 每章預設 2 次充能，於圖騰站補充 |
| 發動條件 | 三人皆存活且靠近；有隊友昏迷時不可發動 |
| 發動方式 | **三人同時按住合體鍵**（RB / R）。需要全隊在同一刻放下手邊的事，這本身就是儀式感，也避免誤觸 |
| 形態 | 巨大圖騰戰士，高攻高防，可移動 |
| 持續時間 | 8–10 秒（暫定） |

**控制權分配（重要）**：三人同時保有輸入，不是一人接管。

| 位置 | 職責 |
|---|---|
| 底層（承重型） | 移動與走位 |
| 中層（位移型） | 輔助與治療 |
| 頂層（遠距型） | 射擊 |

AI 補位時，該部位改為自動瞄準／自動治療。

**UI 需求**：畫面需顯示合體充能剩餘次數。

### 圖騰站

第三章起每章配置 1–2 座。功能：補滿血量、補充合體次數、地圖地標（天然集合點）、敘事節點。

### 治療系統（三層，不綁角色）

**設計理由**：任何遊戲只要有專屬補師，補師就會變成強制選項——玩家會自己得出「不帶青蛙＝找死」的結論，那「完全自由組隊」就是假的。

而且本作**已經不太需要傳統治療**：角色血量歸零不會死，只是倒地等人扶。**救援系統本身就是治療系統。**

| 層 | 管道 | 說明 |
|---|---|---|
| 一 | **扶起即回血** | 扶起倒地隊友時，對方站起來帶一小段血。治療因此成為所有角色都會的通用動詞（見〈角色與隊伍〉通用動詞原則） |
| 二 | **場景補給** | 蘋果、圖騰站、解放被黏合動物時的掉落。實作：`scripts/world/pickup.gd`（回 35，跟扶起同一個量；**滿血時吃不掉、也扶不起倒地的人**——補給要是能救倒地的人，救援系統就被繞過去了） |
| 三 | **青蛙的特化** | 範圍更大、可遠距、不用跑過去。有青蛙很舒服，沒青蛙也活得下去 |

**結果**：治療不再是任何角色的專利，青蛙也沒被削弱——它只是從「必需品」變成「好東西」。
