# 操作與 UI

## 操作配置與 HUD

### 攻擊系統

**單一攻擊鍵，三段連擊。不設輕重擊分鍵。**

**設計理由**：手把配置已滿，加重擊只剩「多佔一鍵」或「長按蓄力」兩條路。而長按蓄力與 Overcooked 基準直接打架——那個基準的核心是回饋要快，蓄力的本質卻是「先等一下」。

| 段 | 頓幀 | 效果 |
|---|---|---|
| 第一下 | 2–4 幀 | 輕快 |
| 第二下 | 2–4 幀 | 輕快 |
| 第三下 | 6–8 幀 | 大擊退，把敵人打飛出去 |

節奏自動產生，玩家不需學習。「第三下把人打飛」正好餵養本作的物理喜劇。

### 情境攻擊

不佔按鍵，變化來自「你正在做什麼」而不是「你按了什麼」。

| 狀態下攻擊 | 結果 |
|---|---|
| 站立 | 三段連擊 |
| 跑動中 | 衝刺撞擊 |
| 跳躍中 | 空中下劈 |

### 疊高不設按鍵

直接走到隊友頭上，站穩後自動吸附，按跳鍵下來。

**理由**：多一個鍵就多一層學習成本。輕度遊戲的核心動詞應該用既有動作完成。

### HUD 設計原則

**核心約束是分屏**（見〈連線、營地與分屏〉分屏規格）。因此原則是：**能放在世界空間就不要放在螢幕空間**。

| 資訊 | 放哪 | 理由 |
|---|---|---|
| 自己的血量 | 螢幕左下（極簡） | 最重要的資訊需要最快的讀取速度 |
| 自己手上拿著什麼 | 螢幕左下小 icon | 同上 |
| 低血量警示 | **畫面邊緣泛紅暈** | 不看角落也知道快死了，小畫面上讀取最快，不佔空間 |
| 隊友血量 | 角色頭上小血條（世界空間） | 跟著人走，不佔邊緣；分屏合併時不需重排 |
| 隊友倒地 | 畫面邊緣方向箭頭 + 圖示 | 分屏下隊友常在視野外 |
| 隊友在畫面外 | 邊緣小箭頭 | 同上 |
| 合體充能次數 | **不常駐**，三人靠近且可用時於畫面下方短暫浮現 | 使用頻率低，不值得佔常駐空間 |

**混合方案的理由**：純世界空間的盲點是「自己的血量最重要，卻放在最難讀的地方」——第三人稱看自己頭頂的小血條，讀取速度遠慢於瞄一眼角落。而傳統四角 HUD 在兩人分屏下會吃掉可觀比例的半畫面。
