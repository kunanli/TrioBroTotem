# 關卡結構

地圖走向：右下營區出發 → 沿河往左上推進 → 頂端 Boss 台地。

> **範圍註記**：本章節描述的是**完整版 5 章**。上市版只做第一、三、五章（見〈[開發里程碑](11-roadmap.md)〉範圍取捨）。第二、四章的內容不會消失，但下方標記 ⚠️ 的項目在上市版會出現缺口，需先解決——見〈[待決事項](OPEN-QUESTIONS.md)〉。

### 第一章・藤蔓谷地

**功能**：教學章｜**時長**：15 分鐘

| 內容 | 用途 |
|---|---|
| 可破壞藤蔓 | 教攻擊與破壞 |
| 兩人合扛原木 | 教抓取與協作 |
| 樹樁 | 教疊高與攀爬 |
| 泥偶 | 教戰鬥與擊退手感 |

**狀態**：四拍都在 `scenes/world/test_arena.tscn` 裡跑得起來（M0），視覺層次做完了（M1）——配色、燈光、路、谷壁、斷崖、終點圖騰。音效還沒有。幾何仍然全部是 Godot 的原始形狀組出來的，沒有任何模型檔。

**下表的七個尺寸一格都沒有動，而且有斷言擋著**：可走幾何與碰撞完全維持原樣，視覺全部長在 x = ±6.5 之外或貼在地面上方 2 公分（不參與碰撞）。唯一動到玩法的是**藤蔓牆從 4 公尺改成 8 公尺**——原本三層疊高（可達 4.51）可以直接翻過去，那是個漏洞。

路是一條會蜿蜒的帶狀網格，**而且瞄準每一拍**：在藤蔓牆前收窄正對缺口、在斷崖兩側各切一個乾淨的斷面（兩個切口隔著 7 公尺互相對望，是最強的「橋要架在這裡」）、在終點前散開。裝飾由 `scripts/world/scenery.gd` 依 `scenery_plan.gd` 的資料長出來，不寫進場景檔——理由與旋鈕位置見 `trio-project/README.md`。

尺寸不是估的，是從實測的移動能力反推的，改任何一個之前請先重新量：

| 能力 | 實測 |
|---|---|
| 單人跳躍 | 高 1.51、水平 5.95 |
| 兩層疊高 | 站上去 1.60、再跳 3.11 |
| 三層疊高 | 站上去 3.00、再跳 4.51 |

| 關 | 尺寸 | 為什麼是這個數字 |
|---|---|---|
| 藤蔓牆 | 寬 4，兩側實心岩塊補滿走廊 | 寬度受限於 `CombatSystem.HIT_RANGE`（2.6，從節點原點量起）。做滿整條走廊的話，站在邊緣打不到，而且沒有任何回饋 |
| 樹樁台 | 高 2.4 | 跳不上去（1.51），兩層疊高上得去（3.11） |
| 斷崖 | 寬 7.0 | 跳不過去（5.95），只能架橋 |
| 原木 | 長 9.0 | 兩端各壓 1.0 公尺在岸上。碰撞用方盒不是圓柱——圓柱橋走起來會滑，而這一段要考的是協作不是平衡感 |
| 終點台 | 高 3.6 | 兩層構不著（3.11），只有三層上得去（4.51） |

**關卡的鎖是「一個人上得去」而不是「三個人都上得去」**：用疊高把人送上高處時，底下的人自己上不來，所以任何「全隊都要上去」的關都是無解的。樹樁台的獎勵因此是把原木弄下來給大家用，不是讓所有人爬上去——而且上去的那個人得是豬（50 > 原木 45），否則他一個人搬不動它。

原木橋用插槽（`log_socket.gd`）吸附定位，不要求玩家精準擺放：要玩家把九公尺的木頭橫跨在斷崖上是在考驗耐性，不是考驗合作。

### 第二章・河岸營區

**功能**：戰鬥入門與控制點

> ⚠️ **上市版不含本章。** 但下表有四項是**首次引入**的教學拍子：控制點、場景補給（蘋果）、寶箱、被黏合的動物。上市版若直接從第一章跳到第三章，玩家會在毫無鋪陳的情況下同時遇到致命魚河、敵族士兵與控制點進階。**這四項的教學責任必須改掛到第一或第三章。**

| 內容 | 用途 |
|---|---|
| Bridge Control A / B | 引入控制點佔領 |
| 敵營帳篷群 | 遭遇戰場地 |
| 蘋果（回血） | 引入場景補給 |
| 寶箱 | 引入探索獎勵 |
| 被黏合的動物（首次） | 引入「打倒＝解放」 |
| 頭目級被黏合動物 | 首次解鎖新動物 |

### 第三章・淺灘與礦車

**功能**：物理解謎主軸，合體技解鎖點｜**這是 M2 垂直切片要做的章節**

> ⚠️ **與上市範圍衝突。** 本章包含「救出頭目級海狸 → 後半段立刻用上築壩／堵水」，但海狸被列為上市後更新（見〈開發里程碑〉Should）。照現況做，M2 會做到一段做不出來的關卡。三個選項：① 海狸提前進 Must ② 本章救出的改成另一隻上市版就有的動物 ③ 本章只做救援演出、能力延後。**須在 M1 結束前決定。**

| 內容 | 用途 |
|---|---|
| 圖騰（首座） | 解鎖合體技、補血、敘事節點 |
| 致命魚河 | 多解法：放石頭／原木墊腳，或遠距型射殺 |
| 礦車（可乘坐、可觸發） | 載具段落 |
| 搬石頭、搬旗子 | 負重與投擲練習 |
| Bridge Control D | 控制點進階 |
| 水中小島寶箱 | 需組合解法 |
| 敵族士兵（首次） | 引入會用場景物件的敵人 |
| **頭目級海狸** ⚠️ | 救出後加入營地，成為可玩角色（與上市範圍衝突，見上方註記） |

> **設計註記**：海狸救出後，該章後半段應立刻安排一處能用上築壩／堵水的路段，讓玩家馬上理解牠在幹嘛。
