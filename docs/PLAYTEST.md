# TrioBroTotem 測試說明

寫給幫忙測試的朋友看的。**不需要安裝任何開發工具。**

---

## 你會拿到什麼

一個檔案：`TrioBroTotem.exe`（約 110 MB）。所有東西都包在裡面，不用解壓縮、不用安裝。

Windows 可能會跳「Windows 已保護您的電腦」——因為這個檔案沒有花錢買數位簽章。
點「**其他資訊**」→「**仍要執行**」。

---

## 怎麼開始玩

需要 **3 個人**（也可以 1–2 人，空位會由電腦補上）。

遊戲的畫面文字全部是英文。開始之前，**在寫著 `your name` 的那一格填你的名字**。
預設是 `Player-483` 這種亂數，
回報問題的時候「Player-483 疊在我身上」對誰都沒有意義。

> 兩個人也玩得到高台：電腦隊友被踩到時會站著不動讓你們疊。
> 只有一個人的話上不去——電腦隊友不會自己疊高。

### 網路模擬（那個下拉選單）

開始畫面有一個「**Network: …**」的下拉。它會**故意**讓連線變慢變差，用來測遊戲在真實網路
下撐不撐得住。**要在開房／加入之前選**，連上線之後就鎖住了。

| 選項 | 什麼時候用 |
|---|---|
| `direct (no simulation)` | 第一次玩，先確認操作沒問題 |
| `LAN 20 ms` | 接近同一個家裡的實際情況 |
| **`typical 80 ms / 1% (acceptance)`** | **這一檔才是真正要測的** |
| `bad 150 ms / 3%` | 想看看極端情況下會爛成什麼樣 |

如果在 `direct` 下很順、在 `typical` 下變得很難操作，那就是我要知道的事——**請告訴我**。

### 第一步：一個人當「房主」

1. 房主打開遊戲，在開始畫面填好名字，按「**Host a room**」。
2. 進到營地之後，左上角會出現一行「**Tell your friends to join: 192.168.x.x**」——把那串數字唸給大家。

### 第二步：其他人加入

1. 打開遊戲，把房主給的數字填進開始畫面寫著 `host address` 的那一格。
2. 按「**Join**」。
3. 出現在營地、左上角的隊伍清單有你的名字，就成功了。

### 第三步：出任務

大家在營地可以先隨便走走、練習抓東西跟疊高。準備好之後，
**走到北邊的任務看板（`Mission Board`）前面按 E**（手把是 LT）就會一起出發。任何人都可以按。
看板上會顯示 `Chapter 1 - Vine Hollow / Press E / LT to set out`。

通關之後會自動回營地，可以再出發一次。

### 連不上的話

| 情況 | 怎麼辦 |
|---|---|
| **大家在同一個家／同一個 Wi-Fi** | 直接用上面的區網位址就好。連不上通常是防火牆——第一次執行時 Windows 會問「允許存取網路」，記得按允許。 |
| **大家在不同的家** | 區網位址沒用。最簡單的解法是裝 [Tailscale](https://tailscale.com)（免費）：每個人裝好、登入同一個帳號，它會給每台電腦一個位址，之後就當作在同一個區網。房主改唸 Tailscale 給的那個位址。 |

## 按鍵

| 操作 | 鍵盤滑鼠 | 手把 |
|---|---|---|
| 移動 | W A S D | 左搖桿 |
| 轉鏡頭 | 按住滑鼠右鍵拖曳，或按 **Tab** 鎖定滑鼠（再按一次解除） | 右搖桿 |
| 跳 | 空白鍵 | A |
| 攻擊 | **J** 或滑鼠左鍵（連按三下有三段連擊） | X |
| 抓起／放下 | **F** | B |
| 投擲 | 抓著東西時，**按住攻擊鍵蓄力，放開丟出** | 按住 RT |
| 互動／扶起隊友 | **E**（按住） | 按住 LT |
| 疊高 | 直接走到隊友身上 | 同左 |
| **卡住了** | **R** 回到出生點 | — |

> 轉視角預設要按著滑鼠右鍵，玩久了手會酸。按 **Tab** 可以鎖定滑鼠，
> 之後移動滑鼠就是轉視角；要點大廳的按鈕時再按一次 Tab 解除。

> 卡進地形、掉進縫裡、被丟到回不來的地方——**按 R**。
> 會回到出生點並補滿血，不用重開遊戲。

## 請幫我試這幾件事

這一版是拿來驗證「三個人一起做事」到底成不成立的，不是完整的遊戲。**沒有劇情，第一章也只是灰盒——營地是練習場，任務關卡是三道用來逼出合作的關卡。**

第 1 項在營地就能試；第 2 項之後都在任務關卡裡，先去看板前面按 E 出發。

1. **走走看。** 轉向、急停、跳。手感有沒有哪裡卡卡的、滑滑的？
2. **打泥偶。** 連按三下攻擊，第三下應該會把它打飛。打起來有沒有「打到東西」的感覺？
3. **互相亂丟。** 按 E 抓起隊友，按住 F 再放開把他丟出去。**豬最重，青蛙最輕**——誰抓得動誰，是規則的一部分。
4. **搬那塊大石頭。** 只有豬（粉紅色那隻）扛得動。
5. **疊高。** 走到隊友身上就會疊上去。**這是最重要的一項。**
6. **爬上北邊那個高台。** 它高 3.6 公尺，跳不上去、兩個人疊也不夠——**只有三層疊高才上得去**。有人站上去，左上角就會出現一行 `*  Cleared.`，然後自動回營地。
7. **摔下來。** 從高台跳下去會受傷倒地，變成布娃娃。隊友走過來按住 E 可以把你扶起來。

畫面左上角有一行「**Stack timer**」，會自動記錄你們三層疊高維持了多久。
**目標是 30 秒**——那是這個專案給自己訂的驗收標準。站上高台只是第一關，
撐過 30 秒才是真正的過關。

> **關於聲音**：現在的音效是程式即時合成的暫時品（命中、落地、投擲、疊高、
> 扶起、通關）。不用客氣，難聽就說難聽——那本來就是要換掉的。

## 怎麼回報問題

照這個格式講，會省下我很多猜測的時間：

```
我在做什麼：（例如「我疊在豬身上，他往前走」）
我預期會怎樣：（例如「我應該跟著他移動」）
實際發生什麼：（例如「我抖了一下就掉下來了」）
別人的畫面：（例如「他那邊看到我還在他頭上」）
```

**最後一行特別重要。** 這是連線遊戲，「我這邊發生了、他那邊沒有」是最難查也最要命的一種問題。
測的時候麻煩偶爾看一下旁邊的人的螢幕。

當機或整個卡住的話，告訴我當下在做什麼就好。
