# TrioBroTotem 測試說明

寫給幫忙測試的朋友看的。**不需要安裝任何開發工具。**

---

## 你會拿到什麼

一個檔案：`TrioBroTotem.exe`（約 110 MB）。所有東西都包在裡面，不用解壓縮、不用安裝。

Windows 可能會跳「Windows 已保護您的電腦」——因為這個檔案沒有花錢買數位簽章。
點「**其他資訊**」→「**仍要執行**」。

---

## 怎麼開始玩

需要 **3 個人**（也可以 1–2 人，空位會由電腦補上）。

### 第一步：一個人當「房主」

1. 房主打開遊戲，按左上角的「**開房**」。
2. 開好之後，畫面上會出現一行「**叫朋友連：192.168.x.x**」——把那串數字唸給大家。

### 第二步：其他人加入

1. 打開遊戲，把房主給的數字填進「host 位址」那一格。
2. 按「**加入**」。
3. 左邊的隊伍清單出現你的名字就成功了。

### 連不上的話

| 情況 | 怎麼辦 |
|---|---|
| **大家在同一個家／同一個 Wi-Fi** | 直接用上面的區網位址就好。連不上通常是防火牆——第一次執行時 Windows 會問「允許存取網路」，記得按允許。 |
| **大家在不同的家** | 區網位址沒用。最簡單的解法是裝 [Tailscale](https://tailscale.com)（免費）：每個人裝好、登入同一個帳號，它會給每台電腦一個位址，之後就當作在同一個區網。房主改唸 Tailscale 給的那個位址。 |

## 按鍵

| 操作 | 按鍵 |
|---|---|
| 移動 | W A S D |
| 轉鏡頭 | 按住滑鼠右鍵拖曳 |
| 跳 | 空白鍵 |
| 抓起／放下 | E |
| 投擲 | 按住 F 蓄力，放開丟出去 |
| 攻擊 | 滑鼠左鍵（連按三下有三段連擊） |
| 疊高 | 直接走到隊友身上 |
| 扶起倒地的隊友 | 走到他旁邊按住 E |

手把也可以用。

## 請幫我試這幾件事

這一版是拿來驗證「三個人一起做事」到底成不成立的，不是完整的遊戲。**沒有劇情、沒有關卡，就是一個練習場。**

1. **走走看。** 轉向、急停、跳。手感有沒有哪裡卡卡的、滑滑的？
2. **打泥偶。** 連按三下攻擊，第三下應該會把它打飛。打起來有沒有「打到東西」的感覺？
3. **互相亂丟。** 按 E 抓起隊友，按住 F 再放開把他丟出去。**豬最重，青蛙最輕**——誰抓得動誰，是規則的一部分。
4. **搬那塊大石頭。** 只有豬（粉紅色那隻）扛得動。
5. **疊高。** 走到隊友身上就會疊上去。**這是最重要的一項。**
6. **爬上北邊那個高台。** 它高 3.6 公尺，跳不上去、兩個人疊也不夠——**只有三層疊高才上得去**。有人站上去就會顯示「已通關」。
7. **摔下來。** 從高台跳下去會受傷倒地，變成布娃娃。隊友走過來按住 E 可以把你扶起來。

畫面左上角有一行「**疊高計時**」，會自動記錄你們三層疊高維持了多久。
**目標是 30 秒**——那是這個專案給自己訂的驗收標準。

## 怎麼回報問題

照這個格式講，會省下我很多猜測的時間：

```
我在做什麼：（例如「我疊在豬身上，他往前走」）
我預期會怎樣：（例如「我應該跟著他移動」）
實際發生什麼：（例如「我抖了一下就掉下來了」）
別人的畫面：（例如「他那邊看到我還在他頭上」）
```

**最後一行特別重要。** 這是連線遊戲，「我這邊發生了、他那邊沒有」是最難查也最要命的一種問題。
測的時候麻煩偶爾看一下旁邊的人的螢幕。

當機或整個卡住的話，告訴我當下在做什麼就好。
