# TrioBroTotem

> 三隻笨拙的動物疊在一起才叫圖騰，也才叫團隊。

三人連線的輕度合作冒險遊戲。玩家扮演不同族的動物，一邊打怪推進、一邊用物理互動解開場景謎題。核心樂趣不在操作精度，而在「三個人一起把一件簡單的事搞得很複雜」。

**目前狀態**：設計階段（GDD v0.3）｜尚未進入 M0 技術驗證

---

## 規格摘要

| 項目 | 決定 |
|---|---|
| 引擎 | Godot 4 |
| 視角 | 3D 第三人稱跟隨鏡頭 |
| 人數 | 1–3 人，缺額由 AI 夥伴補上 |
| 本地分屏 | 2 人＋動態分屏（**上市後更新**） |
| 章節數 | 上市版 3 章，完整版 5 章 |
| 每章時長 | 15–20 分鐘 |
| 美術風格 | 低多邊形卡通風 |
| 打擊感基準 | Overcooked（回饋速度優先） |
| 平台 | PC / Steam |

## 三條不可違反的設計規則

這三條是其他所有設計的前提，改動任何一條都會牽動整份文件。

1. **重量即規則**——長頸鹿 > 豬 > 海狸 > 蛙 > 貓 > 雞。這一個數值同時決定抓取、疊高順序、擊退距離、浮力、敵人強度讀值。
2. **通用動詞保底**——任何謎題都能用「抓、丟、疊、推」解決。角色專屬能力只是捷徑，不是唯一解。
3. **誤傷的擊退永不可關**——只有扣血可關。因此任何謎題都不得設計成「必須靠扣血誤傷才能解」。
